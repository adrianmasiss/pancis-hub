# 07 — Sistema de diseño

## Dirección visual

Pancis Hub debe sentirse limpio, moderno, deportivo y confiable.

## Inspiraciones

- Notion: estructura y claridad.
- Apple Health: datos y gráficos.
- Spotify: descubrimiento.
- Nike Run Club: motivación.

## Temas

### Claro

- Fondo principal neutro claro.
- Superficies ligeramente diferenciadas.
- Texto de alto contraste.
- Bordes discretos.

### Oscuro

- Fondo profundo, no negro absoluto.
- Superficies elevadas.
- Texto legible.
- Estados de color moderados.

## Principios

- Mobile-first.
- Espaciado generoso.
- Máximo una acción primaria dominante por sección.
- Gráficos fáciles de interpretar.
- No depender exclusivamente del color.
- Animaciones funcionales, no decorativas.

## Tipografía

Usar una familia sans-serif de alta legibilidad. Mantener una escala consistente para títulos, subtítulos, cuerpo, etiquetas y datos.

## Iconografía

Íconos simples, consistentes y reconocibles. Evitar mezclar estilos.
