# 04 — Historias de usuario

## Perfil

- Como usuario, quiero crear mi perfil para recibir objetivos adaptados.
- Como usuario, quiero registrar restricciones alimentarias para evitar recomendaciones inadecuadas.
- Como usuario, quiero elegir modo claro u oscuro.

## Nutrición

- Como usuario, quiero ver qué debo comer hoy.
- Como usuario, quiero cambiar una fuente de carbohidratos por otra equivalente.
- Como usuario, quiero ajustar una porción y ver cómo cambian los macros.
- Como usuario, quiero guardar comidas frecuentes.
- Como usuario, quiero ver cuánto me falta para cumplir mis objetivos.

## Entrenamiento

- Como usuario, quiero ver mi rutina del día.
- Como usuario, quiero registrar peso y repeticiones.
- Como usuario, quiero consultar mi sesión anterior.
- Como usuario, quiero sustituir un ejercicio cuando no tengo el equipo necesario.
- Como usuario, quiero visualizar mi progreso de fuerza.

## Seguimiento

- Como usuario, quiero registrar mi peso.
- Como usuario, quiero ver tendencias y no solo valores aislados.
- Como usuario, quiero comparar mediciones corporales.
- Como usuario, quiero almacenar fotografías privadas.
- Como usuario, quiero importar manualmente valores de un InBody.

## Diario

- Como usuario, quiero completar el diario en menos de un minuto.
- Como usuario, quiero descubrir relaciones entre sueño, hambre y rendimiento.

## Academia

- Como usuario, quiero aprender por qué recibo una recomendación.
- Como usuario, quiero ver referencias y nivel de evidencia.

## Asistente

- Como usuario, quiero indicar qué alimentos tengo y recibir una opción.
- Como usuario, quiero reorganizar el día cuando comeré fuera.
- Como usuario, quiero entender por qué mi peso no cambia.
