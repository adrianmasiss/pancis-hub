# 04 — Gobierno científico

## Promesa correcta

No prometer “100 % comprobado”. Prometer recomendaciones trazables basadas en la mejor evidencia disponible, con limitaciones, nivel de confianza y fecha de revisión.

## Jerarquía

1. Guías y consensos reconocidos.
2. Revisiones sistemáticas y metaanálisis.
3. Ensayos controlados.
4. Estudios longitudinales.
5. Estudios agudos, biomecánicos o EMG.
6. Opinión experta y contenido educativo.

Un estudio EMG puede informar excitación muscular aguda, pero no prueba por sí solo hipertrofia regional longitudinal.

## Grados

- **A:** evidencia consistente y aplicable.
- **B:** favorable con limitaciones.
- **C:** evidencia indirecta o limitada.
- **D:** hipótesis, inferencia biomecánica o práctica.

## Registro de afirmaciones

Cada claim debe incluir texto, dominio, población, resultado, grado, referencias, limitaciones, vigencia, revisor y fecha.

## Macronutrientes

No usar un único número universal. Trabajar con rangos, objetivo, fase energética, entrenamiento, composición corporal, preferencias y seguridad.

## Revisión

- Revisión trimestral de reglas críticas.
- Búsqueda mensual de novedades.
- Alertas de retractación.
- Versionado.
- Aprobación humana antes de cambiar reglas de alto impacto.

## Formato de respuesta

Separar datos del usuario, cálculo, evidencia, inferencia, recomendación, limitación y acción.
