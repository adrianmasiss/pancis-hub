# 03 — Requisitos funcionales

- **RF-001:** dieta y rutina tienen versiones.
- **RF-002:** distinguir planificado, seleccionado para hoy y consumido.
- **RF-003:** guardar snapshots nutricionales históricos.
- **RF-004:** toda sustitución es reversible antes de confirmar.
- **RF-005:** mostrar original, sustituto, porciones, diferencias, score y limitaciones.
- **RF-006:** validar cálculos finales en servidor.
- **RF-007:** mostrar fuente de alimentos y afirmaciones.
- **RF-008:** no calcular compatibilidad completa con datos esenciales faltantes.
- **RF-009:** la compatibilidad de ejercicio depende del contexto.
- **RF-010:** soportar regiones musculares cuando la evidencia lo permita.
- **RF-011:** el chat utiliza herramientas para cálculos.
- **RF-012:** cada recomendación científica enlaza a fuentes.
- **RF-013:** la IA requiere confirmación para modificar datos.
- **RF-014:** mantener historial auditable.
- **RF-015:** cálculo y registro básicos funcionan sin IA generativa.
- **RF-016:** ante fallos externos, ofrecer datos locales o entrada manual.
- **RF-017:** mostrar fecha, tipo y nivel de evidencia.
- **RF-018:** aplicar aislamiento estricto entre usuarios.
