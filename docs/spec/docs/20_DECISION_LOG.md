# 20 — Registro de decisiones

- **ADR-001:** reenfocar el producto en sustituciones y contexto.
- **ADR-002:** cambios diarios no sobrescriben planes.
- **ADR-003:** cálculos determinísticos, explicación generativa.
- **ADR-004:** arquitectura free-first.
- **ADR-005:** evidencia trazable y versionada.
- **ADR-006:** 3D sin falsa precisión.
- **ADR-007:** score de compatibilidad, no ranking universal.
- **ADR-008:** generación automática queda fuera del MVP.
- **ADR-009:** alimentos externos seleccionados se normalizan y guardan localmente.
- **ADR-010:** funciones básicas siguen disponibles sin IA.
