# 02 — Flujos de usuario

## Cambiar un alimento hoy

1. Entrar a “Hoy”.
2. Abrir una comida.
3. Seleccionar el alimento.
4. Pulsar “Cambiar solo hoy”.
5. Buscar, indicar alimentos disponibles o preguntar a la IA.
6. Seleccionar un registro de la biblioteca.
7. Optimizar porción.
8. Ver comparación, diferencias, compatibilidad, fuentes y ajustes.
9. Confirmar.
10. Recalcular macros restantes sin alterar el plan base.

## No sé qué usar

El usuario elige una prioridad: macros similares, proteína, rapidez, economía o disponibilidad. El motor genera candidatos y la IA explica los mejores.

## Sustituir una comida completa

El sistema intenta aproximar el vector nutricional de la comida mediante una receta o combinación limitada de alimentos y propone ajustes para las comidas pendientes.

## Cambiar ejercicio en el gimnasio

1. Abrir la sesión.
2. Seleccionar ejercicio.
3. Pulsar “Cambiar solo hoy”.
4. Indicar equipo disponible o molestia.
5. Comparar región, patrón, ROM, estabilidad, perfil de resistencia y fatiga.
6. Confirmar una alternativa.

## Pregunta libre

El orquestador obtiene el plan, datos alimentarios, estado del día y evidencia; ejecuta herramientas; responde con cálculo, explicación, fuentes y una acción confirmable.

## InBody

El usuario registra una medición, indica condiciones de prueba, visualiza los segmentos disponibles y compara tendencias sin presentar estimaciones como certezas.
