# 15 — Pruebas y validación

## Nutrición

Pruebas unitarias de conversión por 100 g, porciones, macros, score, optimización, tolerancias, combinaciones, restante y redondeo.

Golden tests revisados por nutricionista y property tests para asegurar valores no negativos, score 0-10, exclusión de alergias e inmutabilidad histórica.

## Alimentos

Normalización USDA/Open Food Facts, datos faltantes, duplicados, barcode, crudo/cocido, caché y fallos externos.

## Entrenamiento

Score, regiones, equipo, dolor, sustituto idéntico, evidencia insuficiente y volumen. Validación por especialista.

## IA

Herramienta correcta, cálculo correcto, cita existente, solicitud de datos faltantes, confirmación y seguridad.

## Biometría

No inventar datos segmentales y mantener alternativa accesible.

## E2E

Crear cuenta, plan, día, búsqueda, sustitución, confirmación, comida, restante, sustitución de ejercicio, serie, InBody, chat, cierre y persistencia.

## Release gate

No publicar si existe acceso cruzado, cálculos inconsistentes, pérdida de históricos, modificaciones sin confirmar o citas inexistentes.
