# 18 — Prompt maestro para adaptar el sistema existente

Actúa como un equipo senior de producto, software, nutrición deportiva, ciencias del ejercicio, biomecánica, IA, datos, seguridad y QA.

Trabaja sobre el sistema Pancis Hub existente. No añadas funciones indiscriminadamente. Reenfócalo en:

1. Sustituciones nutricionales puntuales.
2. Sustituciones de ejercicios puntuales.
3. Datos biométricos e InBody.
4. Copiloto IA con herramientas y evidencia.
5. Biblioteca científica trazable.

## Primera acción

Audita el sistema y compara su estado con todos los documentos de este paquete. Entrega inventario, módulos reutilizables, funciones que deben salir del flujo principal, brechas, riesgos, migración de datos y plan.

## Reglas

- No reconstruir sin necesidad.
- No modificar planes base al aplicar cambios diarios.
- Separar planificado, modificado y consumido.
- Usar herramientas para cálculos.
- Mostrar fuentes.
- No inventar biomecánica.
- No usar EMG como prueba directa de hipertrofia.
- No afirmar certeza total.
- No modificar sin confirmación.
- Mantener funciones esenciales sin IA.
