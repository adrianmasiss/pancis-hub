# Pancis Hub — Especificación maestra resumida

## 1. Problema

El usuario ya tiene una dieta y una rutina, pero necesita flexibilidad diaria sin perder el control del plan.

Ejemplos:

- Hoy no tiene huevos, pero sí pancakes.
- Está cansado de comer la misma fuente de carbohidratos.
- La máquina del ejercicio está ocupada.
- Siente molestias con una variante.
- Quiere saber si un ejercicio alternativo enfatiza la misma región muscular.
- Quiere comprender cuánto se aleja del plan al realizar un cambio.

## 2. Solución

Pancis Hub mantendrá una copia del plan base y permitirá crear una **excepción diaria**.

La excepción:

- no modifica la dieta o rutina original;
- muestra antes y después;
- calcula diferencias;
- ofrece alternativas;
- permite confirmar o descartar;
- guarda lo realmente consumido o realizado;
- actualiza el restante del día;
- deja trazabilidad.

## 3. Los cuatro módulos del MVP

### A. Hoy — Nutrición

- Ver dieta del día.
- Marcar comidas.
- Sustituir alimento o comida.
- Buscar alimentos.
- Comparar macros.
- Ajustar porción.
- Recalcular el día.
- Preguntar a la IA.

### B. Hoy — Entrenamiento

- Ver rutina del día.
- Sustituir ejercicio.
- Comparar músculos y región.
- Consultar compatibilidad.
- Registrar series.
- Pedir una recomendación de series/repeticiones.
- Guardar el cambio solo para hoy.

### C. Progreso e InBody

- Perfil biométrico.
- Historial.
- Carga manual de resultados.
- Cuerpo 3D segmentado.
- Comparación entre fechas.
- Advertencias sobre incertidumbre de BIA.

### D. Copiloto IA

- Chat global.
- Acciones contextuales dentro de comidas y ejercicios.
- Acceso a perfil, plan y estado del día.
- Cálculos mediante herramientas, no por improvisación del modelo.
- Respuestas con evidencia y nivel de confianza.

## 4. Fuera del MVP

- Generación automática completa de dietas o rutinas.
- Diagnóstico clínico.
- Reconocimiento visual de alimentos.
- Evaluación técnica por cámara.
- Panel para profesionales.
- Marketplace o red social.

## 5. Definición de éxito

El MVP es exitoso cuando un usuario puede entrar, ver su plan, sustituir un alimento o ejercicio, comprender las diferencias, registrar lo realizado, consultar al asistente con contexto y revisar las fuentes utilizadas.
