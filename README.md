# Pancis Hub

Plataforma inteligente para mejorar la composición corporal mediante nutrición, entrenamiento y seguimiento personalizado basado en evidencia científica.

## Estado del proyecto

Fase inicial de definición y documentación del producto.

## Objetivo principal

Ayudar a cualquier persona a mejorar su composición corporal mediante nutrición, entrenamiento y seguimiento personalizado basado en evidencia científica.

## Enfoque inicial

- Recomposición corporal.
- Idioma español.
- Interfaz clara y oscura.
- Experiencia inspirada en Notion, Apple Health, Spotify y Nike Run Club.
- Arquitectura preparada para crecer hacia un producto comercial.

## Pilares

1. **Ejecutar:** nutrición, entrenamiento, recetas, planificación y registro.
2. **Aprender:** contenido educativo basado en evidencia.
3. **Analizar:** seguimiento, patrones y recomendaciones personalizadas.
